# Both Methods — Complete Guide

---

## 🅰️ METHOD 1: Without Opening the App (Terminal Only)

**When to use:** When you just need outputs — CSV files, charts, reports — no GUI needed.

### Just 1 Command:

```bash
python scripts/run_pipeline.py
```

**That's it.** This single command does everything:
1. Loads data
2. Cleans data
3. Creates features
4. Runs analysis
5. Generates 18 charts
6. Saves to SQLite
7. Exports CSV files

**Time:** 10-15 seconds

---

### Where to See Output:

| Folder | What You Get |
|--------|-------------|
| `data/processed/` | `retail_sales_clean.csv` (clean data) |
| `images/` | 18 PNG charts |
| `output/` | Analysis CSV files |
| `reports/` | `insights_summary.md` (summary) |
| `retail_sales.db` | SQLite database |

---

### Extra Commands (optional):

```bash
# Fast run (skip plots)
python scripts/run_pipeline.py --skip-plots

# Use synthetic data
python scripts/run_pipeline.py --synthetic

# Run tests
pytest tests/ -v

# Individual modules
python src/data_cleaning.py
python src/analysis.py
python src/visualization.py

# Run SQL queries
sqlite3 retail_sales.db < sql/03_basic_queries.sql
```

---

## 🅱️ METHOD 2: With the App Open (GUI)

**When to use:** When you want an interactive dashboard — click to view charts, explore sections, upload CSVs.

### First-Time Setup:

```bash
pip install streamlit plotly
```

(Do this only once)

### Then Run Daily:

**Step 1:** Create a new `app.py` file (use the fresh code from the previous message)

**Step 2:** In terminal, run:

```bash
python -m streamlit run app.py
```

**Step 3:** Browser opens automatically:

```
Local URL: http://localhost:8501
```

If it doesn't open automatically, **open your browser manually** and type: `localhost:8501`

**Step 4:** In the sidebar, click **"🚀 Run Analytics Pipeline"** button

**Step 5:** Wait 5-10 seconds → dashboard fills up → explore the 12 sections

---

### What You Can Do Inside the App:

**In the sidebar:**
- **Data Source** — 3 options:
  - Synthetic Data (auto-generate)
  - Upload CSV (your own data)
  - Existing Raw File (already present)
- **Run Button** — runs the pipeline
- **Navigation** — 12 sections:
  1. Executive Overview
  2. Regional Performance
  3. Category Performance
  4. Product Portfolio
  5. Discount & Pricing
  6. Time-Series Trends
  7. Customer Analytics
  8. Payment Behaviour
  9. Profitability Split
  10. Data Explorer
  11. Data Quality
  12. Downloads

**In each section:**
- Interactive charts (zoom, hover, pan)
- Tables (sort, filter)
- KPI cards
- Download buttons

**To stop it:** Press `Ctrl + C` in the terminal

## 🚨 Common Problems

**Method 1:**
- `python: command not found` → try `python3`
- `ModuleNotFoundError` → run `pip install -r requirements.txt`

**Method 2:**
- `streamlit: command not found` → use `python -m streamlit run app.py`
- Page appears blank → press `Ctrl + C` and restart
- Button doesn't work → check terminal for errors
